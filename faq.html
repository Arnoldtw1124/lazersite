FREQUENTLY ASKED

// 常見問題資料庫

01 // 訂購與交期

一般件製作時間為確認圖檔與款項後的 3-5 個工作天（不含國定假日）。若為展會或急件需求，請先私訊告知排程，我們會盡力協助安排。

當然可以！我們專精於個人化客製服務，即使是「單件」作品也全心投入雕刻。同品項大量製作（10件以上）亦提供批發優惠。

02 // 檔案與圖樣準備

可以的！請盡量提供解析度高（300dpi以上）的照片或白底黑線手繪稿，背景越單純雷射對比效果越好。我們也可協助進行基礎排版與簡單去背。

雷射雕刻是利用高能量光束燒灼或汽化材質表面，因此呈現出的顏色主要取決於材質本身的物理特性（例如木質呈現深褐焦黑、壓克力呈現磨砂霧白、陽極金屬露出生鋁銀色），無法像UV彩色印刷那樣指定 Pantone 彩色色號喔。

03 // 出貨配送與售後保證

我們配合超商取貨（7-11 / 全家）以及郵寄掛號/宅配包裹。若為大型展會（如 FF/CWT），亦可協調於現場攤位直接交付。

若因工坊端疏失導致雕刻內容與雙方最後確認的對稿圖檔不符，或運送過程嚴重破損，請於收到貨後 3 日內拍照回報，我們將無條件全額負擔為您重新雕刻補寄！
