WORKFLOW

// 職人工藝・客製化製作流程

Phase 1: 接單與需求確認

Inquiry & Consultation

目標：確認需求可行性，並篩選掉有版權風險的訂單。

  • • 需求諮詢：確認品項 (軟木杯墊 / 皮革鑰匙圈 / 展會價目牌 / 其他)、數量與交期。
  • • 版權確認 (重要⚠️)：
    - 文字/名字：確認字型風格（手寫風、黑體等）。
    - 圖片：確認是否為原創或授權圖。我們尊重創作者，恕不接受未經授權的官方圖或同人圖。
  • • 小撇步：建議提供黑白線稿 (JPG/PNG) 或向量檔 (AI/SVG)，雷射單色線條效果最佳。

Phase 2: 設計與排版模擬

Design & Mockup

目標：讓您「看見」成品，減少彼此對成品的視覺落差。

  • • 合成模擬圖 (Digital Proof)：我們會將您的圖案合成在實際材質 (軟木/皮革/木板) 照片上，傳給您確認大小位置。
  • • 參數設定 (CAM)：依照材質厚度與特性，精確調整雷射功率、雕刻深度與走刀速度。

Phase 3: 精準雷雕加工

Production

目標：職人精神，精準執行，確保最高解析度品質。

  • • 機器架設與對焦：使用固定治具確保材料平整，並進行光學精確對焦，這是刻印清晰的關鍵。
  • • 路徑預覽：在弱光模式下再次確認路徑邊界，確保圖案完美落在材料中央，絕不歪斜。
  • • 正式雕刻/監控：全程人工監控雷射運作，確保安全與細微線條完美焦黑呈現。

Phase 4: 細緻後處理

Post-Processing

目標：去除焦痕與雜質，提升手感與成品手作溫度。

  • • 清潔 (Cleaning)：軟木使用軟毛刷清除凹槽黑灰；皮革使用專用清潔布擦拭表面粉塵。
  • • 除味 (Deodorizing)：成品會靜置於通風環境散去雷雕天然燃燒焦香氣味。

Phase 5: 包裝與出貨交付

Packaging & Delivery

目標：創造極致開箱體驗，是我們對每一位委託者的承諾。

  • • 質感包裝：使用牛皮紙封套或防震防刮霧面袋，兼具保護與簡約科技美感。
  • • 專屬心意：附上工坊感謝小卡，讓這份作品獨一無二。
  • • 出貨通知：完成後會拍照給您確認，隨即寄出或於展會面交。
