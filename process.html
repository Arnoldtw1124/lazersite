// CRAFT WORKFLOW

職人工藝・客製化製作流程

從初始概念溝通、數位光學模擬，到微米級雷射雕刻與質感封裝，為您把關每一個關鍵細節。

PHASE 01 // 需求確認

接單諮詢與版權把關

INQUIRY & COPYRIGHT SCREENING

核心目標：快速確認品項可行性、交期與細節，並嚴格把關版權風險。

  • 品項規格：確認客製基底（軟木/皮革/壓克力/金屬）、數量與希望交付日期。
  • 版權確認 (重要)：我們尊重原創者，僅接受您擁有著作權或授權之圖稿，恕不接受無授權同人或官方侵權商標。
  • 小撇步：提供高對比黑白單色線稿 (AI, SVG, PNG) 能呈現最極致的雕刻銳利度。
PHASE 02 // 數位模擬

數位排版與合成模擬

DIGITAL PROOF & CAM TUNING

核心目標：讓您在雕刻前清晰「預覽」成品比例，消弭視覺預期落差。

  • 真實材質合成圖：將您的向量圖樣合成至實際材質（軟木孔隙、皮革紋路或金屬反射）提供線圖確認。
  • CAM 參數精算：依據材質吸光率與焦距，精細設定雷射能量、點陣密度與走刀速度。
PHASE 03 // 精密加工

光學治具定位與精準雷雕

MICRO-PRECISION LASER ENGRAVING

核心目標：職人校準工藝，確保 0.01mm 級的同軸聚焦與銳利線條。

  • 專用固定治具：量身訂製開模治具固定工件，確保絕對平整，無熱變形。
  • 弱光紅外線預覽：在不傷材料的前提下實機預覽邊界外框，保證居中對齊。
  • 全程人工監控：逐件把關焦黑度與層次深度，呈現深邃焦糖感。
PHASE 04 // 細膩質檢

細緻後處理與除味工序

POST-PROCESSING & QUALITY AUDIT

核心目標：掃除加工焦塵與雜質，昇華手感與觸覺質感。

  • 微孔粉塵清除：軟木使用專業軟毛刷清理微孔黑灰，皮革使用保養級專用拭布拂去碳化痕。
  • 恆溫通風除味：雕刻完成後置於專用通風防塵架，散去天然灼燒木質煙燻氣味。
PHASE 05 // 極致開箱

防震包裝與安全交付

SECURE PACKAGING & EXPEDITION

核心目標：賦予作品完美的最後一哩路，送抵您的手中。

  • 科技感保護封套：牛皮紙質密封或抗靜電霧面氣泡防震包裝，兼具安全與前衛美感。
  • 工坊銘謝小卡：隨件附上工坊卡與保養建議，增添儀式感。
  • 出貨前拍照回傳：封箱前拍照傳送至私訊，確認無誤後寄出或於展會面交。
